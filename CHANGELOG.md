# Changelog

## 2026-08-14

- Contact form now delivers for real: it builds a `mailto:` message (subject, body, sender name and address) and hands it to the visitor's mail app, with the address shown as a fallback — the fake "Message Sent!" state is gone.
- Replaced the cloned site's two portrait photos (hero identity layer, about profile) with neutral KG monogram placeholders generated by `scripts/generate-placeholders.mjs`; dropping real photos at the same paths needs no code change. `scripts/download-assets.mjs` no longer re-fetches the target author's photos.
- Skill cards no longer claim Advanced/Proficient levels (those were unverified assumptions); the pill now shows the skill's category instead.
